# Image Setup Instructions

## How to Add Real Jaipur Images

Since external image URLs are blocked by CORS, you need to download images and place them here.

### Required Images:

1. **amer-fort.jpg** - Amer Fort main view
2. **hawa-mahal.jpg** - Hawa Mahal (Palace of Winds)
3. **city-palace.jpg** - City Palace Jaipur
4. **jal-mahal.jpg** - Jal Mahal (Water Palace)
5. **sedan-car.jpg** - Side view of a sedan
6. **auto-rickshaw.jpg** - Indian auto rickshaw
7. **motorcycle.jpg** - Motorcycle side view
8. **suv-car.jpg** - SUV/large vehicle

### Where to Download Free Images:

1. **Pexels** - https://www.pexels.com/
   - Search: "Jaipur", "Amer Fort", "Hawa Mahal", etc.
   - Click "Free Download"
   - Save to this folder

2. **Pixabay** - https://pixabay.com/
   - Search for Jaipur landmarks
   - Download free images
   - Save to this folder

3. **Unsplash** - https://unsplash.com/
   - Search for "Jaipur India"
   - Download (not just copy URL!)
   - Save to this folder

### Steps:

1. Visit Pexels.com
2. Search for "Amer Fort Jaipur"
3. Click on a good photo
4. Click "Free Download" button
5. Save as "amer-fort.jpg" in THIS folder
6. Repeat for all images

### Important:
- DOWNLOAD the images, don't just copy URLs!
- Name them exactly as listed above
- Supported formats: .jpg, .jpeg, .png, .webp
- Recommended size: 800-1200px wide

Once you add the images here, refresh your browser to see them!
